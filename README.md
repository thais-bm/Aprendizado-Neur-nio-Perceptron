# Neurônio Perceptron - Aprendizado Supervisionado
Implementação prática do algoritmo Perceptron de camada única (*Single-Layer Perceptron*) para resolução de problemas de classificação binária linearmente separáveis.

## 📌 Objetivos
- Compreender a regra de aprendizado do Perceptron (atualização de pesos e viés).
- Implementar a função de ativação degrau/sinal.
- Treinar o modelo com dados supervisionados e avaliar a convergência.

## 🛠️ Tecnologias
- Python 3
- NumPy
- Matplotlib (para visualização da fronteira de decisão)
